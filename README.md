# 🖼️ Motivation Meme Project

Este é um mini projeto de site motivacional feito com HTML e CSS, inspirado no curso "The Complete Full-Stack Web Development Bootcamp". O objetivo é recriar um meme motivacional com uma imagem, título e legenda centralizados e estilizados.

## 🎯 Objetivo

Criar um site simples com os seguintes requisitos:

- Utilizar a fonte **Libre Baskerville** do Google Fonts.
- Exibir um **título (`h1`)** com letras **maiúsculas** e cor branca.
- Exibir uma **imagem personalizada** com borda branca de 5px.
- Usar um fundo preto.
- Centralizar todos os elementos na página.
- Alinhar a imagem e o texto dentro de uma `div` com `width: 50%` e `margin-left: 25%`.
- Garantir que a imagem preencha a largura total da `div`.

## 📂 Estrutura de Arquivos

Motivation-Meme-Project/ ├── index.html ├── style.css └── assets/ └── images/ └── daenerys.jpeg

## 🖌️ Estilo (style.css)

- Fonte personalizada importada do Google Fonts.
- Imagem com largura de 100% e borda branca.
- Texto centralizado e com `text-transform: uppercase` no `h1`.
- Div com margens para centralizar o conteúdo horizontalmente.

## 🧠 Aprendizados

- Uso de fontes externas com Google Fonts.
- Propriedade `text-transform` em CSS.
- Centralização de `divs` usando `margin` e `width`.
- Manipulação básica de imagens com bordas e tamanhos.
- Boas práticas com organização de arquivos (`assets/`, `css/`).

## 🖼️ Resultado Final

Um pequeno site que mostra uma imagem motivacional com frase estilizada, como um pôster digital.
